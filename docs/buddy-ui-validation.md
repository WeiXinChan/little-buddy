# 角色与安装入口验证

TITA-40 基于 `main@09072b123b54173e8d0b0231b8636d9741d9829d`，含 #16 的模拟器回归和 #18 的语音、玩法修复。发布构型的桌面图标启动横屏角色。Debug 保留原模拟入口和独立测试 CA 配置，成品路径在同一 Debug APK 上经显式 Activity 入口跑设备测试。

## 首装操作

1. 成人通过私密渠道取得当前设备的游戏 WSS 地址与设备令牌。地址需使用可信 TLS，路由为 `/v1/animal`。在首次打开的「安装配置」输入并保存，然后进入角色。服务器身份和令牌有效性在首次连接时验证。
2. 点「开始猜动物」，授予麦克风权限。等待「正在听」，然后说话。可提前点「结束录音」。需要中止时点「停止」。互动中再次点「开始猜动物」会清除旧局，并在旧音频释放后开新局。
3. 关闭重开会直接进入角色。连接配置保存在应用不备份目录，以 Android Keystore 的 AES-GCM 密钥加密。需要轮换端点或令牌时由设备持有人清除应用数据，重新走首装。正式配对码交换、短效连接令牌及独立部署接入留给后续阶段。
