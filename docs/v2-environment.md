## 资源与证据边界

本机 `nproc=4`、内存约 3723 MiB、swap 约 1987 MiB；这只是宿主读取，不代表 V2 服务已禁交换。构建、云探针、长时任务及设备操作由协调方登记单个占用者、开始/结束、制品 SHA 和清理结果；本轮未启动构建、服务、安装或云请求。

测试控制器经 Mac SSH/ADB 管理不表示产品运行依赖 Mac。V2 发布业务路径应为手机直连获准后端；审定后用 release 配置验证，不把开发隧道测试当家庭发布路径。现有代理权限禁止卸载清数据/删证书、修改断言和无限重试，复用探针前须移除不相容操作并重新审定，不能直接运行会 pm clear/uninstall 的旧脚本。

设备型号、系统、APK、签名、网络和后端版本需在每次实际设备运行重新记录。历史 OPPO PKW110 / Android 16 / ColorOS 16.0.5 仅作预期，不是本轮读回值。没有真实儿童测试；合成、协议、成人历史记录不证明童声泛化。任何恢复能力不足都如实列依赖，不安排用户录音、点测或试听。
