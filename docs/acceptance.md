# 瓦力 V1 独立设计评审与验收

评审基线为 `requirements.md` @ `a0e1c93`，设计取自 [PR #1](https://github.com/WeiXinChan/little-buddy/pull/1) @ `698bead` 的 `docs/design.md` 与 `docs/development-plan.md`。本次证据为文档走查和下列推演。所有测试均待执行，数值沿用设计计划的建议门槛，需在试验前由用户确认。建议先明确 P1 合同，再由用户确认设计后进入实现。

## 设计问题与修复建议

| 级别 | 文档位置与可复现推演 | 建议及判定 |
| --- | --- | --- |
| P1 | 前台音频、流协议。待机命中后已经有环形缓冲帧，若 WSS 或 ASR 未就绪，孩子短答并立刻点结束，设计没有说明 PCM、`turn.end` 与 `turn.ready` 的顺序。普通轮边录边上传也可能在最终判为空前打开供应商流。 | 明确有效语音门控和 `turn.start` 的时机、就绪前缓冲、封口先后及溢出行为。有效轮按采样位置连续且只封口一次。全程无语音时供应商收到零音频、游戏不推进。定义有限缓冲耗尽和封口前取消的明确回退。 |
| P1 | 流协议与上下文。将 `reply.end` 提前于最后一段实际播尽，或让图片效果晚于揭晓段播放完成，再注入重复 ACK 和下一轮 start。当前只有连续 ACK 和连接顺序，缺少最终段编号、客户端完结条件、后端是否已提交的约定。 | 定义流结束声明、每段结束标记、已排空判据及必要效果的送达顺序。令揭晓图片由确认播放的当前段及其已知元数据驱动。后端按序处理 ACK 与下一轮 start，或显式确认提交。验证图片、题数、下一题各推进一次，无图先于答案。定义播放头只过部分段时的上下文与清除边界。 |
| P1 | 状态与事件。停止时阻塞播放写入或推迟资源释放回调；短时间内再按开始，随后锁屏/恢复，旧释放和旧 capture_ready 交错。文档提出操作号及重建，尚未定义释放超时后的安全重建条件。 | 把即时静音与释放完成作为两项判据。锁屏/后台撤销待办开始，旧完成仅用于确认对应资源归还。确认旧句柄停止且回声保护条件满足才授予录音。无法确认时保持不可录并给出显式恢复。 |
| P1 | 流协议与隐私。首段已播，供应商随后永久停顿；或手机链路半开，旧连接未收到 cancel，随后手机重连。现有首音频限时和空闲 TTL 的触发条件未覆盖所有活跃卡死。 | 明确建连/就绪、首包、段间、整轮和清理截止时间，规定心跳失联后的失效时限。限定活跃轮、会话与供应商并发，旧连接过期后丢弃迟到事件，避免供应商挂起占满额度。 |
| P1 | 隐私。取消后本地和后端清除引用，但代理、SDK、崩溃、交换空间及供应商侧可能有其他副本。服务方案已有核实关卡，缺少可审核的放行记录格式。 | 账号、地域、模型、数据元素逐项记录留存、删除、训练用途与例外，附有效证据和用户批准。验证 App、代理、服务、日志及转储配置，实际走断线、进程退出和 TTL。供应商留存未知或与需求冲突时暂停对应童声云测。 |
| P2 | 前台音频。唤醒尾部保护区包含唤醒词末音，或扬声器尾音触发 VAD。延长观察窗或播放后等待又可能吞掉孩子抢接的首字。 | 在同一 OPPO 音量和路由矩阵比较首字完整率、回授触发、播放后可开口等待。按表现联合调观察窗、时间戳保护区、VAD 和回授间隔。 |
| P2 | 猜动物与语音失败。短词误识别、空语音和真实 ASR 故障可能都落入识别失败；拒绝揭晓后继续猜错，有限线索用尽。 | 区分无语音、低置信、服务失败三个事件，分别走一次追问、确认、显式重试。定义拒绝揭晓后的鼓励和退出路径，避免相同提示循环；覆盖替补耗尽时不虚增题数。 |
| P2 | 资源预算。24 kHz PCM16 下行 384 kbps；手机和供应商两跳，上传在后端是一次入、一次出。稳态有效音频估算约 8.64 GB/月，但积压释放、连线启动与多个供应商流会产生突发。 | 分别测入/出方向、突发、RTT 和队列峰值，核对计费口径。并发、排队、调用上限及超限提示写入配置和证据，构建与压测串行。 |

## 自动测试（模拟适配器、虚拟时钟、确定性调度）

| 编号 / 需求 | 注入与通过判据 |
| --- | --- |
| A1 §3–4 交互 | 每个阶段戳脸/摸头，触摸反馈本地生效，恢复时使用当前状态。开始后无有效采集帧时不显示聆听。分别走单独唤醒、接续指令、手动封口和自动续听。检查就绪延迟、帧重复/缺口、缓冲溢出和关键词裁剪。 |
| A2 §4.2–4.4 取消 | 录音、等待、播放各执行停止与重新开始。排列或固定随机种子打乱 stop/start/封口/锁屏/释放回调，注入旧文本、PCM、表情、图片、错误、VAD、计时器和 ACK。断言最多一个音频所有者，录播无交集，旧事件零可见副作用，状态与资源按截止时间收敛。 |
| A3 §4.3–4.4 协议与恢复 | 掉线、半开、未就绪、首段后断流、权限撤销和音频焦点丢失。分别检查空语音零上传、一次追问后退出、低置信确认、故障提示及显式重试开新会话。模拟播放头段内停、段尾停、重复/缺失/乱序 ACK，检查已听前缀、未说完标记、提交顺序和会话结束清除。 |
| A4 §5 玩法 | 用固定题库和已知种子走满三题，覆盖同义/含糊、猜错无限次、线索递进、拒绝或同意揭晓、有无回应、跳题和替补用尽。断言只在猜对/揭晓完成后计数，图片在答案后展示，同局不重复，只有明确同意才重开。覆盖偏题后回游戏、双向切换、自然退出且无旧局恢复。 |
| A5 §6 内容与数据 | 用合成文本覆盖危险请求、受伤、害怕、姓名和异常长回复。逐段断言过滤先于 TTS，危险时引导找家长，表现白名单生效。在本地可控环境检查 APK 配置、结构化日志、代理/SDK、临时目录、交换与转储设置。正常结束、掉线、TTL、重启后无原始音频和完整聊天持久化；临时会话不跨次复用。 |
| A6 §7–10 构建及资源 | 4 核/约 4 GB 环境单次构建，与负载测试串行；记录构建峰值内存、磁盘和 APK 哈希。单设备循环对话并模拟 3 Mbps 和延迟、抖动、断线，记录 RSS、CPU、队列、带宽、超时、服务调用和费用用量。检查常态 RSS ≤256 MiB、峰值 ≤512 MiB 的建议预算及超限关闭。 |

## 成人 OPPO 真机（用户验收）

1. 记录设备型号、Android/ColorOS、APK 版本与签名指纹，记录音量、距离、桌面摆放、路由、网络与 RTT。验证版本化 APK 能通过个人 Mac 安装，手机和获准后端可在 Mac 离线时完成聊天及三题游戏。
2. 横屏支架上检查停止触达、无文字依赖的状态提示、表情、触摸和待机。播放、等待、录音各执行至少 10 次停止，含连点后立即开始。观察实体时序和端上事件，报告 P95 和异常。建议触摸到呈现首帧 ≤100 ms、停止到可闻静音 ≤200 ms。用现场无留存观测，记录测量误差。
3. 在约 0.5–1 m、安静与电视/成人谈话环境累计至少两小时亮屏待机，按环境报告小时数和误唤醒数，建议 ≤1 次/小时。用成人语音测单独唤醒和连续指令，播放后紧接开口，切换音量及路由，记录漏首字、旧声音被听入、回授和误判次数。
4. 断网、重连、锁屏、切后台、撤权限、焦点抢占分别在录音、等待和播放阶段验证。恢复前台时仅待机；断网时可操作停止、触摸和表情。重试建新会话。核对系统麦克风使用状态及可听输出，结合 A2/A3 轨迹判断旧结果隔离。

## 3–5 岁儿童实际体验（用户验收）

仅在核实供应商和生产配置的数据处理、取得用户批准与监护人授权后进行对应云测。按实际设备、距离、音量、房间背景声、网络和模型版本分组记录。孩子自然参与，可随时结束。保留计数、原因标签、时间和脱敏事件，不保存录音或对话正文。

| 场景 | 建议门槛与记录方式 |
| --- | --- |
| 自然唤醒与接续指令 | 至少 30 次自然唤醒，含单独唤醒、紧接指令和短停顿，命中 ≥90%。另覆盖至少 20 次紧连表达，一遍进入正确场景 ≥90%。记漏首字、误入场景和重复要求。允许两个样本集合重叠，分别标分母。 |
| 自然停顿与听懂 | 至少 30 条自然回答，含犹豫、单字、慢速、同义词与尾音。建议意图一次正确 ≥85%，提前切断 ≤10%。现场记录真实结束和切断判定，另测无声、环境声和低置信确认。 |
| 延迟 | 正常家庭网络下至少 30 次已发出语音的答复尝试，覆盖聊天和玩法，超时/未答计入分母。建议 ≥80% 从实际说完到首个有效可闻段 ≤3 秒。报告成功样本 P50/P90、未答/超时数、RTT、现场标记误差及各阶段时间。等待音不算有效段。 |
| 真实玩法和角色 | 观察一次完整三题、再玩同意/拒绝、提示/换题、切换聊天、退出和无回应。记录孩子能否自行辨认聆听/等待/说话、触及停止、理解角色话语与线索，以及用户对音色的确认。罕见竞态由 A 类和成人真机覆盖。 |

## 验收记录

每项填写用例编号、版本/配置、环境、次数与分母、通过/失败/未测、原因、脱敏事件时间及责任人。不足样本单列待补。V0 记录模拟、交互和安装证据。V1 汇总自动、成人 OPPO 与儿童体验三类结果，由用户确认验收。数据关卡、取消隔离或资源互斥失败时暂停相关发布；童声或延迟门槛未达时记录差距、调整后复测。成人与模拟数据只用于对应阶段的工程判断。
