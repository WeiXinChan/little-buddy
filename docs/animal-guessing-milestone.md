# 猜动物最小闭环与实施验收

## 范围与基线

本里程碑在前台用一次点击「玩猜动物」开局。瓦力先出题，此后一直轮流说话和自动聆听，直到退出。保留手动结束录音及全局停止。完整 V1 仍需前台「瓦力瓦力」唤醒、紧接指令、简短连续聊天、双向切换和手机独立运行。游戏里程碑识别「我想聊天」后清局，简短提示当前体验入口并回待机。聊天接入后同一意图直接进入新聊天，聊天中「玩猜动物」新开一局，永远从空状态开始。

文档基于 `main` 的 `5610c1bcca6845cce07fd77f706beb119c49307c`。需求、总体设计、开发计划及验收在该点与 [PR #6](https://github.com/WeiXinChan/little-buddy/pull/6) 固定头 `61e9d038c293c0c9b47092e4b9f05654da8386f2` 内容相同。核对时 #6 仍为草稿，较 main 改动 28 文件，包含 Android 流式音频、百炼流水线及诊断、私有验证脚本和说明。实施前须由用户确认纳入这条语音基线或经复核的等效变更，再从确认后的目标分支串行实施。Pipecat #7 停留在实验。

**已知证据**（0.1.8）：独立后端 34/34、Android JVM 37/37，用户设备 instrumentation 6/6，假服务两段无杂音并正常回待机，成人正常问候 3/3。手机端点到首 PCM 为 1460/1591/1383 ms，到播放头为 1574/1687/1473 ms（均值 1578 ms）。算法末语音至播放头为 3081/3190/2968 ms（均值 3080 ms）。后端 ASR 收尾 178/175/118 ms，ASR 后首句 552/666/554 ms，首句后 TTS 580/574/554 ms。第二段启动已可与旧 TTS 关闭并行。用户同意继续。实际说完到可闻、回复正文听感、童声表现及完整 V1 均待验。

## 实现选择

推荐沿用原生 Kotlin/Android + 单 Python 后端 + 北京百炼。后端用纯规则处理题库、猜测、提示和计数，固定模板生成核心话术。Android 管界面、现场音频、取消及已播确认。这样可用同一套规则驱动离线脚本、假 ASR/TTS 和真人语音，先定位玩法/时序，再分辨 ASR 和听感问题。后端拥有每个前台互动的短期会话和播放提交，代价是需要增加会话协议及断线清局处理。

沿用 Fun-ASR realtime、qwen3.8-flash、CosyVoice v3 flash / longanyang 的现有配置，录音保留 1.5 秒停顿，保留 PCM 早播和有界逐句合成。默认游戏路径只调用 ASR 和 TTS。明确、安全的偏题可走受限 LLM 单句回复，再由规则追加回题邀请。安全意图先分流，受伤、害怕或危险请求使用固定找家长话术，必要时结束互动。逐句通过内容检查后才给 TTS。LLM 超时、输出不安全或无法表达时用固定回题句。模型无题库写权限，猜测、指令及揭晓授权都由程序判定，模型输出只有话术通道。聊天在后续阶段用同一安全和播放确认机制。

## 题库与规则

后端版本化题库条目包含 `animalId`、显示名、顺序线索、明确别名、易混淆项与 `imageId`。Android 内置同版本的图片映射，启动时协商版本，缺图或版本不兼容时显示简短故障并禁止开局。服务端按局保存已出集合、当前题与线索游标、完成数、猜错数、待确认对象及原问题、静默次数和揭晓决定。用注入种子选题，检查同局替补不重复。新局重置已出集合。会话结束清除内存状态。

首批建议 6 张卡。以下是人工审核起点，实施时核实常见特征、递进关系、描述歧义和别名冲突，并逐张朗读确认简短易懂。

| 动物 | 简短线索，按顺序 | 可接受别名示例 |
| --- | --- | --- |
| 狗 | 有四条腿 / 喜欢摇尾巴 / 会汪汪叫 | 狗、小狗、狗狗 |
| 猫 | 脚步轻 / 有长胡须 / 会喵喵叫 | 猫、小猫、猫咪 |
| 鸭 | 会在水里游 / 脚趾间连着一层皮 / 会嘎嘎叫 | 鸭、鸭子、小鸭 |
| 兔 | 会蹦跳 / 尾巴短 / 耳朵长长的 | 兔、兔子、小兔 |
| 象 | 身体很大 / 耳朵大 / 鼻子像长长的管子 | 象、大象、小象 |
| 长颈鹿 | 身上有斑块 / 能吃高处的叶子 / 脖子特别长 | 长颈鹿、小长颈鹿 |

采用项目原创绘图，统一正面清晰的卡片插画，发布前逐张核实动物、无文字水印及来源。资源清单记录作者、来源、归属或授权、允许改作与随 APK 分发的凭据。审核通过后随 APK 打包，无运行时图床请求。只有揭晓段播完才出现答案图，下一题线索开始前收起，待机、锁屏和停止立即清除。

| 条件 | 状态变化与输出 |
| --- | --- |
| 开局 | 出第一题并播放线索，结束后自动监听。 |
| 最终转写明确 | 规范标点空白和审核过的口语句式，按完整词组和否定/多选语境判定。单个肯定答案匹配当前别名则答对，匹配其他明确动物则温和鼓励并给下一条线索。「是猫还是狗」或自我纠正不靠子串命中。 |
| 含糊、转写空或低置信 | 单候选可用「你说的是……吗？」复述孩子的候选，不说标准答案。肯定后重走规则，否定后回原问题，可直接接受新的明确回答。无候选或无可靠置信字段时用词组歧义和否定规则判断，发通用确认。每次待确认最多追问一次，仍含糊回原问题，保持题数。错误或未知输入不自动算错，也不翻题。 |
| 猜错 / 提示 / 不知道 | 下一条未用线索可用时推进，连续两次明确猜错或提示用尽则征询揭晓。阈值为设计起点。说「不知道」优先给帮助。拒绝揭晓继续同一题，鼓励再猜或提示可换题，剩余线索可应请求使用。耗尽时不用旧提示反复征询，孩子仍可不限次猜，也可主动要求答案。 |
| 同意揭晓 / 猜对 | 说答案并庆祝，揭晓段完整播完显示图，整轮提交后有效完成数加一。给图片短暂停留再播下一题线索或再玩征询，使用可取消的本地定时，停留时长待 OPPO 体验核定。 |
| 换一个 | 清理待确认，从未出题挑替补，完成数不变。没有替补则告知本局题库已用完并结束，进度保留在当次脱敏验收统计中。 |
| 满三题 | 明确同意才开新局，明确拒绝则告别并结束，含糊按确认路径，无声按静默路径。开新局前上一局图片和状态清除。 |
| 甲类静默 / 乙类故障 | 无有效语音时无 ASR/PCM 上行，仅发送受约束的无声控制事件，温和问一次，仍无回应结束。静默次数在有效语音后重置。已送 ASR 但无可用结果走确认。服务故障、失联与超时清局，给本地提示和显式重试，新会话从头开始。 |
| 偏题 / 明确退出 | 偶尔偏题一句安全回应再邀回当前题，线索/完成数不变。明确退出则简短告别，结束本次互动。明确聊天切换按分期清局。 |

「是」「不是」只在明确的待确认、揭晓或再玩语境有效。有冲突的组合回答先澄清，明确退出和安全场景优先。题库审核同时准备正例、否定、多候选、近音、偏题、越权指令、静默和故障夹具。

## 状态与事件接口

玩法状态与语音轮独立。玩法阶段为出线索、等猜测、等确认、等揭晓许可、答案展示、等再玩、结束。语音阶段为待听、录音、等待、播报、等待提交。音频控制器独占捕获或播放槽，从异步打开派发前占用至对应资源释放确认。普通摸头/戳脸立即叠加本地表情，结束时回到当前表情，保持当前语音和玩法；无需发送服务消息。

0.1.8 的 `/v1/turn` 一连接一语音轮，已有 `turn.ready`、`segment.start/end`、`reply.end(count)` 和端上播放清理。建议新增版本化 WSS 会话路线，保留旧路由给单轮验证及回退。会话串行调度，复用现有音频帧、VAD 和供应商适配器。以下事件为拟实现合同。

| 方向 | 事件与条件 |
| --- | --- |
| 手机 → 服务 | `session.start(mode, catalogVersion)` 获得新 `sessionId`；程序创建首个机器人轮。每条事件关联 `sessionId, turnId`，每次开麦/播放另有本地 `opId`，每次停止/开始/离开使本地代际递增。仅当前代际、会话、轮次及匹配操作可更新相应状态。 |
| 手机 → 服务 | 已获聆听许可并开麦，VAD 确认有效语音才发 `turn.start`。收到 `turn.ready` 后送有界 FIFO 的连续 PCM，固定尾采样位置，发一次 `turn.end`。封口早于 ready 时缓存至同一期限。无声发一次 `listen.silence`，不创建 ASR。 |
| 服务 → 手机 | 声明 `segment.start(n)`，按序 PCM，`segment.end(n,samples)` 校验完整性，最终 `reply.end(N)`。揭晓段带 `imageId` 和题次，其他阶段没有答案图元数据。表情限本轮与白名单，可独立到达。 |
| 手机 → 服务 | AudioTrack 的有效播放头越过当前轨道段末且样本数已校验后发 `playback.segment_completed(n)`，此时可展示当前揭晓图。重复回执幂等，未播、取消/flush 后、过早或乱序回执不能推进状态。 |
| 服务 → 手机 | 最终编号 N 已声明且 1…N 都有有效 ACK 时一次应用暂存状态，返回 `turn.committed(N,next)`。声明和最后 ACK 谁先到均可。已播段只进当前会话的短期已听上下文，未播段不进，部分段中断只标「未说完」，不推断具体词句。 |
| 提交后 | 手机核对匹配回执、音频排空且释放完成。next 指示自动聆听、自动出下一条机器人回复或结束。下一机器人轮由手机确认可进入后请求，服务器校验前轮已提交并幂等处理，停留期间取消则请求失效。自动录音还要通过前台、权限、焦点及声学尾音保护。 |

断网、停止、锁屏、退后台、撤权或不可恢复的音频故障使本地代际失效，立即停采集、静音、清队列和图片，尽力发送取消并关闭会话。服务器用连接失效、心跳/会话 TTL 清内存并限时回收上游。未确认的旧释放回调只负责释放对应句柄，禁止在安全释放前授予新录音；清理超时保持不可录并提示恢复。前台恢复只待机。旧 PCM、文本、表情、图片、计时器、ACK、故障和提交不得触发新动作。已播内容的短期状态随清局删除。拒绝旧会话和超前轮次，不做自动重连续局。分别设置连接/ready、首段、段间、整轮、回执、心跳及清理截止时间，按现有有界队列和 0.1.8 诊断校准；单设备单活跃会话，供应商清理重叠仍有并发上限。

## 实施顺序与验收

设计独立复核及用户确认后，按下列串行开工。每项都能在自身入口验收，产出独立证据。表内时限和比例采用总体计划的建议起点。

| 交付 | 验收 | 回退 |
| --- | --- | --- |
| A 离线规则与脚本局 | 固定种子完整三题及再玩，覆盖别名/否定/含糊、提示耗尽、拒绝揭晓、跳题与题库用尽、偏题、切换、静默、部分回复和提交顺序。注入重复/乱序/取消事件，断言计数、进度、图事件和已听上下文。提交人工核查表。 | 保留纯夹具入口，撤回对应规则版本，既有语音无依赖。 |
| B 模拟 APK 可连续玩 | A 后用本地假服务或脚本驱动同一合同，无云调用。OPPO 用户从一次点击玩完三题，检查连续轮流、图只在揭晓后、摸头不断声、拒绝/再玩、停止、锁屏和触控反馈。注入延迟释放、缺 ACK、掉线、旧帧和连点，验证采播互斥和清局。签名 APK、SHA-256、安装步骤。 | 关闭游戏入口，保留旧模拟及单轮 APK。 |
| C 私有百炼游戏及验收 | B 后接通真实 ASR/TTS，先离线协议和故障注入，再经用户核定窗口成人 OPPO 真机。完整三题并同意再开，覆盖别名/含糊、跳过、停止三阶段及重开、弱网和退出。记通过分母、版本、错误与端侧/后端分段时延、真实可闻现场标记、ASR 时长/TTS 字符/LLM token 和实际费用。儿童经下述关卡单独实测。 | 关闭新会话路线及游戏入口，回已验证的 0.1.8 私有单轮配置。 |
| D 手机独立运行 | 单独评审并经用户授权配置受控网络可达的 WSS、有效 TLS、最小权限设备令牌、服务端密钥、撤销/轮换、限流及停服操作。发布签名 APK 和部署、安装、回退说明。用户关闭 Mac、移除 ADB 反向及 SSH 后，以指定 OPPO 和获准网络验证连接、完整三题、清局、断连重开，后续完整 V1 增验聊天。 | 撤销试验令牌和端点，返回原私有通道进行工程联调。SSH 仅为开发便利。 |

V1 后续在已有总体计划 D/F 的范围内交付前台 KWS 和紧接指令、本地回声保护、短聊天与双向切换。用总体文档 A1–A6 及 OPPO 矩阵验收，增加播放结束抢答、漏首字、扬声器回授、后台无录音和模式切换清局。B/C 可先验游戏，V1 仍须合并验证全部入口及 D 的独立运行。

运行与发布门槛：

- 使用结构化脱敏计数、原因和单调时钟，服务端与客户端各自取差；不持久化录音、完整转写或聊天，也不保存跨次身份/偏好。核查 App、代理、SDK、临时目录、日志、转储及会话 TTL。按时长、字符、token、失败及限额记录成本，超限提示并结束；无盲目重试。
- 童声云测须核实供应商账号、区域、模型的留存/删除/训练和例外，附证据并获用户及监护人授权。以 OPPO 目标年龄至少 30 条自然回答验证意图一遍正确建议 ≥85%、提前切断 ≤10%，并现场观察玩法理解、自然停顿、短词和同义。完整 V1 至少 30 次真实答复尝试，包含失败，建议 ≥80% 实际说完至有效可闻首段 ≤3 秒，报告分母、P50/P90、RTT 和现场标记误差。延迟与童声均由用户真机验收，未达或样本不足分别登记。唤醒专项沿用总体验收。
- 锁屏、旧轮回流、音频互斥及数据放行失败时暂停对应试验或发布。4 核 4 GB 机器串行运行重型测试、构建及资源验证。当前设计业务不更动 8443、CA、令牌及联调环境。
