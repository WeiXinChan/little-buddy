## 零采购 TLS 决策

- 优先确认能复用有控制权且可接入的既有域名；当前按无可用域名推进调查。零域名候选为既有稳定公网 IP 的公有 IP SAN 短证书。Let's Encrypt 有效期 160 小时；若既有 TCP/80 服务所有者授权精确 ACME 路径，可用支持 IP webroot 的 Certbot 5.4+；否则只有接入方明确准许 TCP/443 且 ACME 客户端能验证 IP 标识符和 TLS-ALPN-01 时才试该挑战。先用 staging 演练签发、续签、原子切换和代理重载，再验证 OPPO 使用 IP 字面量且无域名 SNI 时的真实信任链、IP SAN 和错误证书拒绝。证书剩余期限、续签告警和到期关闭属于放行项。[Let's Encrypt IP 证书](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability) · [Certbot IP 证书](https://letsencrypt.org/2026/03/11/shorter-certs-certbot) · [ACME 挑战](https://letsencrypt.org/docs/challenge-types/)
- 只读监听检查确认本运行环境有 80、未见 443，与 #17 的宿主历史观察相符；公网 IP 稳定性、443 外部可达、监听归属、安全组/防火墙及管理权限待协调方核实。由运营方和实际接入商确认地域、IP 试验、ICP/APP 备案适用性与部署边界。保护现有 80、8443、8444、9444，切换和回退只触及专用入口。公有方案条件不成立时，仅在已有获准、能脱离 Mac 独立到达的私网中另评应用专用 CA，限定信任目标并保留服务端身份校验及轮换；若该网络也不存在，则手机独立接入仍阻塞。[Android 信任配置](https://developer.android.com/privacy-and-security/security-config) · [#17 接入设计及监管出处](https://github.com/WeiXinChan/little-buddy/pull/17)
- 单设备撤销/轮换一并关闭已有连接；云密钥与管理员凭证留在服务器，APK 只经配对领取设备凭据并用 Keystore 保护。连接、会话、帧、队列、请求时限及重试明确有界。核对已有百炼账号/地域/模型的留存、删除、训练用途和例外，连同生产日志配置及授权记录通过才可进入童声云测。

**放行结论**：静态设计通过，TITA-40 可在协调方确认基线后推进；#18 的 CI 与 TITA-36 复核是其合入关卡，可与无冲突的静态工作错开。P0 为可信独立接入、数据关卡和签名成品固定版本证据；P1 为成品入口/表现、聊天提交与切换、同流唤醒、#18 回归与复核。当前可交设计评审，成品发布须以上述验证闭环为准。
