# 瓦力 V2 技术设计与契约草案

状态：TITA-79 / M01，2026-11-24，供 TITA-93 独立技术评审；未实现、未执行产品测试。适用年龄 5–8 岁。批准依据为三份 V2 附件，原文逐字保存；附件中的“交接前/未下发”是历史状态，当前执行状态见 [环境与依赖](v2-environment.md) 和 [追踪表](v2-traceability.md)。后续先评审再实施，由协调方串行放行，不重复请求常规产品确认。

## 推荐方案与关键取舍

推荐延续 Kotlin 原生安卓、端上 KWS、流式 ASR → 一个统一主 LLM → 安全批准的短句 TTS，Python 异步后端保持单设备内存会话。保留现有严格 SSH/TLS 传输的候选能力，V2 隔离包、后端实例、端口和凭据，不修改 V1 生产配置。实际隔离标识和端口在实施前登记，不能直接套用 V1。

现仓库为原生 Activity/View 路径，继续扩展眼睛绘制和临时图片层，不为 V2 引入 Compose 迁移。AGP 8.13.2、Kotlin 2.2.21、compile/target 36、min 26 是现仓库事实；兼容承诺限经过验证的 OPPO。Python 继续复用现有 websockets/httpx 适配层，不新增未经必要性验证的 Web 框架。

分层语音便于控制已播事实、安全、取消和图片时机，但会增加串联延迟；端到端实时语音仅作为 M12 对照。百炼北京是已有供应商线索，不是 V2 定版。质量、安全及数据条件满足后再按相同场景选择模型、音色和固定版本。不每轮便宜模型试答再贵模型重答，不默认长推理。图片以审核素材库优先，特殊场景异步生成；不得假设已开通生图服务。

主 LLM 统一理解聊天、四类玩法、换规则和角色变化；确定性代码维护事实、权限、截止时间、资源和副作用。不能把 V1 固定题库当 V2 主玩法。候选意图、事实变更和工具参数须符合受限 schema，模型文本没有授权效力。角色、答案、线索、情节和规则按版本保存；长期画像和声纹均不进入设计。

## 状态与轮次契约

由端上串行归约器统一控制状态；后端按设备串行处理业务事件。状态分为音频、会话、管理三条受约束的轴，避免把“等待思考”和“结束会话”混同。

| 状态/事件 | 契约 |
| --- | --- |
| Inactive | 后台、锁屏、权限失效或音频路由失效时立即撤销输出、释放收播；前台恢复只进入待唤醒 |
| WakeIdle | 端上短环形缓冲与 KWS；不持续上传环境音，不主动搭话 |
| Listening / ThinkingWait | 唤醒续说保留首字；声音与语义共同决定封口；短词有效、附和按上下文处理；P01–P03 均为待调参数 |
| Generating / Speaking | 维持有界任务与流式播放，仍保留端上插话检测；主 LLM 不占停播关键路径 |
| OutputSuspended | 可疑表达立即暂停并保留进度和续说音频；仅确认噪声/非插话才能恢复，识别失败不视为噪声 |
| ConfirmedInterrupt | 立即静音、撤销旧输出代际，继续听完整表达；“停”后沉默不自动续播 |
| QuietWait / WakeIdle | 临时离开安静等待；无有效互动按 P04 待唤醒，内存会话按 P05 过期；播放和有效请求不算普通沉默 |
| End / Handoff | 明确告别、单独换人清空正文、摘要、私密事实和任务；保留设备设置；交换游戏角色不误清会话 |
| ParentVerify / ParentManage | 进入即取消旧输出并停止对话收音；原会话继续计过期时间；退出待唤醒，不能复播 |

音频是最大风险：V1 收播互斥不能满足 V2 播放中短词插话。推荐受控全双工：一个 AudioRecord、一个 AudioTrack，本地 VAD/回声处理持续监听有效会话内的插话，候选声先暂停再判定；禁止“与机器人文字相似就过滤”。先核 OPPO AEC、音源、路由和双讲行为，再调阈值。API 存在不能证明效果；AEC 可用性和创建均需检查，设备可能不支持。[Android AEC 官方参考](https://developer.android.com/reference/android/media/audiofx/AcousticEchoCanceler)

同一输入用绝对采样位置聚合，KWS 命中前后的有限保护窗口去重交接。轮次以声音活动、语义完整性、当前问答、思考信号共同判定；“嗯”在同意、附和、犹豫中分别处理。“对，但是”及尾音重叠不可只按字数丢弃。调参须用 A06–A09 和声学测试验证，不能承诺文本判定覆盖所有口音。

## 取消与资源所有权

每个事件携带 `connection_epoch, session_id, turn_id, output_epoch, task_id, sequence`；同一设备单个有效连接和活动轮。客户端/后端分别验证身份、有效期、当前状态和顺序。模型、音频、图片、安全回调、ACK 和定时器全部遵守同一校验，未知字段/无效序列拒绝；不把提示词当协议校验。

撤销顺序：先递增输出代际并静音/清队列，再取消上游与工具，最后收集资源释放确认。确认插话保留会话和完整新输入；告别/换人清空会话；管理保留会话至原期限。清理完成回调只能释放其原句柄，不得改变新轮状态。取消超时不把旧句柄当已释放；相应资源进入不可用，禁止无界重建。所有队列设置字节/条数上限和背压；起点建议音频待播不超过约 1 秒、文本待合成 2 段、图片 1 个在途，M02 注入溢出与关闭失败后由 M04 校准。

同一原请求最多一次安全且幂等的重试，总等待从确认表达结束算起且不重置；P09 轻反馈不算有效回复，P10 到期撤销。额度不足使用适配器确认的独立分类，无依据不伪装断网。失败、退出、换话题以后旧结果不能重放。已收不到客户端心跳时，后端独立清理内存和任务；租约起点建议 15 秒，配置与长轮进度分别验证，不能延长会话数据期限。

## 已播事实与图片提交

事实分为 `proposed / approved / sent / played_confirmed / partial_unknown / cancelled`。正文、摘要和游戏状态分别记录“已听公共进展”“尚未揭晓秘密”“计划变更”。主 LLM 上下文不得把 sent 当已听；摘要压缩必须保留秘密答案、已给线索、角色、当前规则和中断标记。

短句分段附唯一 segment ID、连续音频采样范围和 effect ID。客户端以对应 AudioTrack 播放头确认连续完成段，ACK 仅作工程播放进度证据，不保证外部可闻；网络发送完成、TTS 完成或时钟估计均不构成播放确认。后端只提交当前轮已发送完整的连续段前缀，重复 ACK 幂等，越序不补推断。段内打断若无可靠词级对齐，则记 partial_unknown，不宣称整句已听。

谜底尽量独立为短段；揭晓图须关联该段已播确认和当前话题版本，再展示一次。图像 ready 只是准备完成，不可揭晓。部分播放不确定时宁可不展示，并在下一轮必要时简短补足，不能从未来答案推断过去已听。玩法中已确认的公开事实不会因后续段失败被整轮回滚；尚未播出的剧情不进入摘要。迟到图、工具结果和模型输出同时受 session/turn/output/topic version 校验。生成上限 P08 与会话期限取较早；延长/收起按语音操作，失效及时释放。

## 安全、多人和管理

安全输入分类与主 LLM 配合，危险求助优先让出游戏；输出在每个可播短句、图像及工具副作用前通过必要检查，拒绝检查失败时放行，保留本地安全帮助提示。针对正常好奇/危险指导成对检查漏拦及过拒。模型不自行通知外部人员，不索取私密身份，也不将安全事件自动转成正文采样。M10 检查从 TITA-93 和各阶段断言开始。

多人不做声纹识别。重叠意图不拼接，含糊时澄清；任何人可停播和求助。角色交换保留共同状态，明确单独交接默认新会话；共享故事只携带可公开的剧情，不能泄漏私人聊天和秘密谜底，无法可靠分离时新开。退出一人和全体结束分别处理。

家长页屏幕输入 6 位 PIN，语音和自称身份不授予权限；错误限次、冷却和闲置锁定采用持久且防重启绕过的计数，起点建议 5 次失败冷却 60 秒、管理闲置 2 分钟（待独立评审，不是批准产品阈值）。PIN 用随机盐的慢哈希验证，验证材料结合 Android Keystore 保护；不记录输入、截图或明文。启动/重装/升级和恢复都不得删除配对或把无 PIN 当默认开放。

“停止对话收音”指关闭儿童 ASR/云上传和上下文入口；管理期间的“取消/退出”由独立端上有限命令识别处理，音频只在内存，不能落入儿童会话或日志。该识别器不处理配置写入，不识别 PIN；取消与返回也须有无障碍屏幕路径。离线命令能力未实现，M08 必须验证，不能因停收音而丢失语音退出要求。首次 PIN 初始化只允许受认证的配对/系统凭据管理流程，禁止任意儿童首次打开即设置；具体初始化与恢复绑定在 M08 评审，未完成不开放受保护写入。

优先系统凭据认证后重置应用 PIN，不能以屏幕已解锁等同重新验证。Android `isDeviceSecure` 仅报告有无安全锁屏；旧 `createConfirmDeviceCredentialIntent` 已弃用且无凭据可能返回 null。候选采用系统 BiometricPrompt 的设备凭据认证，真机验证成功/取消/进程重建/旧回调重放。无安全凭据或能力不足时关闭此恢复路径，备用恢复码/后台授权须另有契约与评审，不自动引入万能口令。当前 D04 未满足，不宣称恢复可交付。[Android KeyguardManager 官方参考](https://developer.android.com/reference/android/app/KeyguardManager)

## 数据与问题材料契约

原音、转写、回复、摘要、生成图默认仅内存、任务结束释放；会话明确结束/到期双端独立清理，不因网络断开遗留。禁正文日志、SDK 请求 dump、异常原文和完整会话；无正文日志最多 7 天。服务与进程禁含正文 core/交换落盘，V1 已有保护证据只作参考，V2 独立实例复测。通用素材与本地失败提示可持久保存，不携儿童内容。供应商副本单独核实 D05。

问题材料适配器不绑定具体平台，未确认接收/回复/删除能力前仅做契约和合成夹具。设备凭据只访问本机问题；维护者最小权限，与儿童通道隔离。选择日志范围后才上传，允许纯说明，不默认附录音、截图或整周日志。以随机幂等键支持分块/部分上传撤回，取消未提交草稿即清除。服务端设置不可变 original_submitted_at，回复、备注、补充不能改写。

| 状态 | 转移与显示依据 |
| --- | --- |
| 待发送/发送失败 | 本地事实，不伪装服务端已收；重试沿用幂等键 |
| 已提交/处理中/已回复 | 服务端确认；已回复不等于已解决，只在家长页显示 |
| 删除请求待发送 | 离线撤回先隐藏材料及停本机处理，尚不宣称服务端停止 |
| 正在删除 | 服务端收到请求即原子撤销人员访问/处理；部分上传也纳入 |
| 已删除 | 服务端确认所有受控副本完成才显示，确认本身也不永久留单号 |
| 删除失败/逾期 | 诚实呈现并向运维暴露无正文告警；原到期删除独立运行 |

删除截止 `min(received_withdrawal_at + 24h, original_submitted_at + 7d)`；未撤回按原单 7 天。服务端 UTC 为持久截止基准，运行计时使用单调时钟，客户端不能延长截止。未提交的部分上传使用短租约，起点建议 1 小时，取消立即撤销；不能通过永不提交绕过清理。删除范围含正文、附件、副本、缓存、索引、下载和内部备注；不进长期备份。依赖平台不能提供硬删除或副本边界时禁止接收真实材料。源运行日志按自身最多 7 天独立处理，撤回不能误报清空源日志。

清理采用立即拒绝访问、耐久删除任务、重试、截止前告警、独立到期扫描；起点建议每分钟扫描并在期限前留足重试余量，权限检查同时拒绝已过期对象。拒访问不等于物理删除。仅在 D06 验证所有副本后允许“已删除”。恢复备份前先应用删除账本/到期过滤；账本仅必要标识且不超原期限，不为审计永久留可回溯副本。默认问题存储不备份，方案由维护者和评审核实。

## 验证与发布门槛

M02 先提供可控时钟、合成音频、事件乱序/重复/迟到、关闭失败和额度/网络故障；M03–M09 每阶段带对应确定性断言及独立安全检查。M11/M12 分开报告协议、设备与声学结果，所有失败/超时计入分母；普通回复与插话分别建议至少 100 次，60 分钟混合测试记录资源曲线和账单。实际声学输入起点至可闻首声/停声由同一外部时基观测，播放头不能替代。

M13 才做发布配置全矩阵；严重安全/隐私、旧结果污染、PIN 绕过、超期删除或未处理主链故障阻止完整交付。D03 声学设施、D04 恢复、D05 数据条件、D02/D06 问题平台未核实的受影响功能不能报告通过；不阻断独立契约与合成基础设施。最终由 M14 提供完整 APK、版本哈希、后端匹配、测试限制和回退说明，用户只一次整体体验。所有重型构建和手机占用由协调方串行，不自动合并或公开部署。
