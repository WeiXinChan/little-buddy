# Concrete image review ports

`ModelImageReview` implements the prompt and PNG review ports required by `QwenImages` using an explicitly configured Beijing `qwen3.8-flash` chat-completions client. Construct it with reviewed workspace/key/policy IDs and inject `prompt_reviewer=review.prompt, image_reviewer=review.image`. It has no environment/credential defaults and does not enable images or change `live.py` composition.

The prompt request contains only the bounded minimal description. The image request contains only a canonical, bounded generated PNG as a data URI and a fixed review instruction. Neither carries conversation, audio, scope, nonce, identity, cookies or client default query fields. Responses must contain one finished assistant JSON decision with exactly one literal boolean `allow`. Denial, ambiguity, truncation, duplicate fields, malformed input, HTTP errors, redirects, cancellation or timeout do not approve an image. Receipts bind the exact reviewed bytes, caller nonce and policy ID; the generator still rechecks scope and its original overall deadline. The model policy is a content safety signal, not a guarantee of suitability.

References: [official visual model capabilities](https://help.aliyun.com/en/model-studio/text-generation-model/), [official visual input format](https://help.aliyun.com/zh/model-studio/vision), [official image API](https://help.aliyun.com/en/model-studio/qwen-image-generation-and-editing-api-reference).

Validation: `python3 -B -m unittest discover -s tests/v2 -p test_image_review.py -v`. Seven targeted methods cover request minimization, PNG digest binding, actual generator→prompt reviewer→image reviewer rejection, malformed/truncated decisions, bounded HTTP failures and cancellation. All requests use synthetic HTTP transports; supplier inference requests zero. Live composition, reviewed runtime configuration, account permissions and actual model safety/effectiveness remain pending. A successful read-only permissions query with no matching authorized records is not proof of inference permission or its denial.
