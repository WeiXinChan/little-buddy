## 实际路径与取舍

`backend.v2.live` 显式组装既有 DashScope 地域端点、ASR/TTS、
`DashScopeModel → UnifiedProviders → VoicePeer → Session`。仅监听回环，
使用调用方提供的 TLS 和设备凭据；启动前关闭进程 core dump。
本次没有启动持久服务，账号配置只读，凭据没有写入仓库或输出。

统一模型覆盖普通聊天、轮流猜描述、共编故事、角色冒险、联想轮流说；
以结构化计划表达规则、角色、隐藏谜底和待播短句，不是固定题库。
语义端点接 M04 的完整/未完/思考以及新轮/停播/附和/噪声/不确定接口。
真实样本与固定响应测试分开记录，不能把接口接通当全部语义验收。

采用现配 qwen3.8-flash 的供应商 JSON Schema 约束，保留全部本地校验；
其他模型仍使用 JSON Object 加本地校验，不假定支持同一供应商能力。
计划整体及每个短句在合成前检查；单句计划复用该句整体检查。
明确虚构角色扮演不等于谎称现实亲历，现实危险步骤、排他关系、索取隐私
和虚假通知仍拒绝。错误、非法模型结果、安全检查失败均不继续播报。
响应预算不因这些检查或重试延长；不自动重试或另开收费服务。

JSON Schema 只约束形状，不证明事实和安全语义正确。该取舍用一次结构化计划
换取可信状态提交与校验，也增加生成等待；本轮延迟不是首声声学性能。
[供应商结构输出说明](https://help.aliyun.com/en/model-studio/qwen-structured-output)
明确 JSON Object 不保证字段结构，Schema 模式支持 Qwen3.8-Flash。

## 记忆来源、压缩和隐私

儿童输入独立于机器人已播事实。近期窗口最多 8 条，保留 child/played、
轮次、私事标记；不要求姓名等真实身份。模型选择的儿童事实必须逐字来自本轮原文，
程序计算 span，本地再次核实。条目同时保留完整 source_text 和 evidence_only：
裸“猫”不自动等于“孩子现在喜欢猫”。后续模型必须核对主语、否定、时间、疑问及纠正。

每类来源保留当前值加最多 3 条来源历史，允许不同偏好并存；总儿童来源候选
最多 16KiB，先淘汰最老历史，不能无限记忆。写入前检查完整候选，
无法在总容量内安全保存则拒绝，不能部分覆盖已有来源。
否定、过去、妹妹的偏好、疑问、纠正及动物/颜色两个维度均有窗口淘汰后的回归。

机器人短句和游戏状态仅在对应连续完整段播放 ACK 后提交，ACK 不是声学证明。
未播、段内不确定、取消和迟到不能冒充已听。关键剧情/线索/谜底等 anchors
绑定当前完整播放短句，来源带 segment/turn；模型不能直接写自由摘要。
角色规则状态在最后短句完整 ACK 后提交，避免未播规则先成为已发生剧情。

压缩在约 40 条记录、80 个已揭晓 ID 或上下文约 24KiB 时主动执行。
模型只能选择已有已播事实索引，本地验证快照身份和版本、索引、重复；
自动保留最近 8 条事实，保护项单独保留，不允许摘要删除或改写。
公共和私事分别压缩，近期窗口、source_text、保护项、游戏/谜底、
待播短句及其 anchors 都计入原 64KiB 内容上限。上限没有提高。

每种可见范围保留至多 16 个机器人保护项；当前 plot.main/goal/location/inventory、
clue/answer/rule/role/promise.current 不被普通历史 anchors 挤掉，旧背景先淘汰，
避免达到固定数量后永久拒发。这个来源机制不能证明模型标注了每一项重要事实；
A12 的整体语义质量仍需非作者复核，不用“选 24 条”代替完成证明。

共享投影排除私事来源、私密回复和隐藏谜底。退出私事后普通模型上下文也不再看到
私事来源。跨玩法保留公共剧情和当前角色/规则；明确放弃可退出当前玩法。
明确单独换人使用旧 Session.handoff 清除全部上下文/任务/绑定代际，创建随机新 session ID，
随后走客户端 stop/epoch、新绑定和重新生成，沿用原首回复截止。
旧 ACK、摘要、图片/工具身份及迟到失败不能撤销或修改新参与者状态。
角色交换本身不创建新会话。结束及 600 秒 TTL 均清除来源、摘要和秘密。

## R97-04 与设备边界

Capture 用完整 KWS 尾边界及缓存样本数折算单调时钟时间，传给真实 VoiceClient。
solo 的本地首回复预算在发送前启动，截止为该唤醒边界 +15 秒；
solo 等待、owner 延迟、重复 tick/wake/心跳/服务端 open 均不续期。
服务端收到非负 age_ms 建立同一剩余预算，重复 solo 不重建 prepared。
首有效完整播放回执解除首回复预算；过期由真实客户端 pump 关闭连接并调用资源释放。

新代码 3/3 通过。另测延迟唤醒、发送前预算、重复唤醒及有效播放解除。
这是作者复跑独立用例，不是本轮非作者审定，solo/唤醒/A18 不标 PASS。

新增认证 TLS 黑洞夹具 `python3 -m backend.v2.blackhole` 和
`V2AudioTest#soloNoServerFramesLocallyCancelsRealVoiceClient`，使用真实 WebSocket/Handler，

## 供应商条件与剩余限制

只读既有项目配置确认北京地域和模型别名 fun-asr-realtime、
qwen3.8-flash、cosyvoice-v3-flash/longanyang，合成调用证明这些接口当前可用。
账号主体、账号侧留存/人审/诊断投递/备份/逐请求删除、真实货币账单和固定服务快照仍未核实。
API token 用量不等于费用账单，不以未知条件声称儿童数据已获云服务放行。

2026-11-24 核对的[官方数据留存政策](https://www.alibabacloud.com/help/zh/model-studio/data-retention-policy)
有默认保留及 ZDR 例外；其 ZDR 控制说明限定国际站及列出的非内地区域，
不能据此声称当前北京业务空间已零留存。沿用 TITA-71 的中国站逐接口证据缺口；
本轮仅发合法合成内容，没有真实儿童录音、身份或完整聊天入库。

推荐继续以现配 qwen3.8-flash 加来源/Schema/安全门作为可落地候选，不把不可用的别名当备选已验证。
M12 仍需更大同场景样本、账单、快照和声音定版。真实儿童泛化、完整实云 ASR/LLM/TTS
单链路性能、60 分钟稳定性及所有手机声学均未测。
F03/A12/solo-A18 整体保持 OPEN，不邀请用户做过程试听或分项测试。
