# M06 眼睛与语音入口

基于未合并 PR #35 `d84f32484fd368386e1fe85f111d161da952a615`，依赖其 PR #34/#33/#32/#31 链。PR 基分支保持 `agent/tita-83-unified-companion`，不合并或更改 V1 生产。

## 实现边界

V2 launcher 默认直接渲染 EyesView Canvas，两眼使用独立的屏幕横向/纵向尺寸，横屏优先，无常驻文字/按钮/菜单。待配置与重启仍显示眼睛；未配置唤醒反馈故障眼睛，不伪装理解。

LISTENING 由真实输入/回复完成触发，WAITING 由无输出时的静音触发，THINKING 由生产 endpoint 提示触发，SPEAKING 只由实际 AndroidTrack 播放头进展触发，不由 PCM 到达触发；故障与待唤醒分别联动错误与 gate 事件。

同一 AudioRecord 的独立本地关键词通路识别“瓦力瓦力进入管理页面”“取消”“退出管理页面”，管理期间只跑有限词检测，不上传/缓冲儿童表达。进入先撤本地播放和图片、增加输出 epoch；管理期间忽略迟到网络事件，退出清 gate、回待唤醒。进入与退出使录音代际票据失效，防止管理前排队 PCM 在退出后补传。后端识别到完整管理命令后在 context/endpoint/LLM 前路由；讨论管理的合成反例仍走普通语义路径。自然说法泛化及实际 KWS 声学表现未验证，R14/F01 保持后续责任。

无全脸长按，无万能 PIN、假验证或受保护配置写入。家长验证页只显示禁用的 PIN 字段与取消，完整 PIN 验证/恢复由 M08 实现。管理识别通路在未配置联网服务时也可本地运行；未授录音权限时不能声称语音入口可用。不增加预算页面。

未配置初始化/返回使用明确 `local_kws` 模式，VoiceClient 不 connect，不持有地址/凭据，无网络发包；允许新本地 recorder 待唤醒，旧句柄仍需释放。显式 startVoice 之后设置连接曾启动标记，HOME/锁屏/失焦返回不自动重建 recorder/socket，不读取 V1 配置；仍需受认证配置通路显式 startVoice。既有 V2AudioTest 的旧资源 requireReleased 与禁止自动恢复断言未删除或削弱。M08 负责持久配置后显式连接策略。

图片由服务端已播事实 reveal、客户端实际完整段播放及 epoch/topic 门控驱动。普通 listening/speaking 不清图片；超时 4 秒回眼睛；撤销/管理/换轮立即撤图。M06 不提供未审素材，不下载任意 URL；M07 接入审核过的本地 catalog resolver。模拟器图片测试使用明确标注的纯色合成 patch，证明真实 Android 图片视图时序，不证明生成素材质量。

真实窗口截图、代理视觉检查及 CI 实际结果在取得后补记；未取得前不得将本文件写为渲染验收通过。OPPO 安装、链信任、独立声学/儿童声、锁屏/撤权真机责任保留，不由布局或模拟器测试关闭。用户无需过程点测/试听。

首轮0截图：原始 emulator.log 由协调侧取回核实为 Unknown AVD name v2eyes / ini 路径不一致；显式 ANDROID_AVD_HOME 对应此问题。第二轮0截图：Pulse heredoc 未展开路径；配置实测修正。第三轮模拟器启动及两包安装成功，实际1项测试在 recorder readiness 失败；pa 音频驱动警告不足以单独判根因。第四轮未执行 instrumentation：launcher 探针缺 MAIN 且未核解锁，输出 No activity found；不能据此判产品 Manifest 有误。
