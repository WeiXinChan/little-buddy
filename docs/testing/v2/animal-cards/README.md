# 猜动物固定题库

生产入口为 `python3 -m backend.v2.live`。默认关闭。root 审核 `backend/v2/animal_cards.py` 中四张卡的全部线索、确认和再提示后，在现有 V2 启动命令末尾增加 `--animal-cards`。在实际拉起进程的持久 service 定义或受管启动脚本保存完整原命令和新参数；若修改 systemd 定义，执行 daemon-reload 后按原 V2 流程重启。检查新进程实参包含该开关。仅在临时 shell 增加参数不能跨重启保留。回滚为去掉此参数、重新加载并重启 V2。没有客户端或数据迁移。

初始兔子题只接受完整的猜动物邀请。最终播放 ACK 后才可用当前题库题目核对有限动物名、别名和陈述式作答。换题按兔子、大象、长颈鹿、斑马循环。题卡只使用源内固定正文，不插入输入、模型正文或私有历史；现有输入、本地片段检查和 TTS 仍执行。省略 PLAN/FACTS/模型审核仅限这些固定句对，不把游戏中的孤立动物名提取为孩子事实。猜测问句、引用、否定、多个答案、同音近似和复合要求沿用原模型路由。现进程、会话和已提交题目不能由模型自行声明题库身份。重连后不恢复题库身份。

离线验证：`scripts/with-build-lock python3 -B -m unittest tests.v2.test_animal_cards`。线上最小复核是不同措辞的三轮和一次未确认交付的中断，核对真实首音/最终播放 ACK、换题与自由输入分流。模拟 ACK 不证明真机播放或儿童识别准确率。
