# M03 生产会话模块与模块级实测

适用5–8岁。交付 `backend/v2/session.py`，无网络/供应商/安卓依赖，不被V1入口导入。不是复制 `lab.py`：生产层不引用tools；合成适配器反向调用生产模块，lab仅提供可控时钟。

## 集成接口

每设备在单一事件循环独占一个Session，注入单调秒时钟。`begin_turn()`仅在确认儿童完整有效表达后调用，开始独立总等待预算；`valid_interaction()`用于其他经确认有效互动。试用默认P05=600秒（从最后有效互动起）、P10=15秒；可配置，不是声学调参结论。heartbeat只刷新15秒连接租约，管理活动不得调用互动刷新接口；不可恢复过期对象。双方各自运行poll定时器与本地结束清理，不能依赖对方回执。

`bind_player(handle)`在创建真实播放器后调用，重建会撤销旧输出；随后`task(id)`签发六维Identity。每任务序号必须从0连续增加，未知/乱序/重复拒绝，拒绝不消耗序号。模型/安全/TTS/工具结果均以`accept`校验后才能影响业务；不要先做副作用再校验。安全批准结果必须关联同一identity；`approved=True`只能由受信任安全适配器传入，不能直接接模型或客户端同名字段。

`send`登记实际已发送、安全批准的完整段及从0开始连续采样终点；ACK适配器必须将播放头绑定同一真实播放器对象、stream、段和当前identity，不能把网络完成或估算时间转换成ACK。先发后ACK，连续前缀逐段提交，段内为partial_unknown。所有flush/stop/rebuild/wrap/route-loss必须先`reset_player`，再处理其旧回调。image_ready绝不揭图，只有答案完整段ACK产生reveal命令；图片适配器执行前仍需检查identity、topic及安全批准，不可仅凭effect字符串显示旧图片。

每次变更后必须立即`drain_commands()`，按顺序同步执行mute_flush，再cancel_release；这些命令是集成契约，不是已完成物理释放的声明。适配器须维护原句柄的释放确认/超时隔离，关闭失败资源不得重建或复用；不能让旧释放回调改变新轮。命令队列128条溢出抛BufferError，调用方应停止输入并排空，禁止忽略异常继续业务。硬件静音、真实任务取消与关闭失败恢复在M04接入，本模块不声称已验证。

`context()`返回确定性事实投影，禁止任意模型摘要回写公共已听事实；含已播公共前缀、当前规则/角色、未揭秘密和私事。共享模式去掉秘密和私事；private必须由上层明确分类，模块不提供自然语言隐私识别。共同故事只能携带该公开投影，无法分类时直接handoff。角色交换用change_game保留公共事实；单独换人/告别用handoff/clear，创建新对象且不复用旧ID。

public/private/game/secrets/pending合计JSON UTF-8上限64KiB；游戏/私事超限抛BufferError，待播超限返回False，均不写入候选内容。已播段最多128个，满时拒发，不静默丢关键事实；后续需独立评审有界压缩策略。任务和待播段默认各2；标识上限128字符；不确定段最多保留128个。生产调用方不应直接修改属性。上下文返回深拷贝，不含日志/落盘。配对与设置由对象外管理。

## 模块级实测命令与范围

仓库根目录：

```
python3 -m unittest discover -s tests/v2 -v
python3 -m unittest discover -s tools/v2_harness/tests -q
python3 -m tools.v2_harness.r94_check --out /dev/null
```

13个模块测试方法，0失败/0异常/0超时（unittest未设独立watchdog，执行小于1秒）；子场景不膨胀分母。覆盖六维身份、乱序重复、队列、部分播放、五类流重置、旧安全/图像回调与ACK、重连、独立预算一次重试、公共事实/秘密/私事、结束/换人/期限、心跳不续期、有效互动持续1200秒后静默至1800秒清理、混合总容量。时间推进是合成时间，非真实长聊。适配器独立字面oracle校验停播后旧ACK不得提交；空返回、None、伪造成功及故意错误Session子类全部被拒绝（4项负控在一个测试方法内）。

M02原28项工具测试及21项R94负控回归通过；未修改evidence.py的通用产品PASS禁用边界。A04/A10–A13/A25/A33只有上述软件子契约证据，整项不置PASS；无Android/真实语音/LLM/云服务/声学/儿童数据。F03仅提供本阶段软件证据，M04集成和真机声学前保持OPEN；F01/F02在M08、F04/F05在M09继续OPEN。未接管理PIN或问题材料路径。
