# 瓦力 V1 总体设计

依据 [需求基线](../requirements.md)。本文为评审稿，架构和参数均为推荐起点。设备行为、童声表现、地域网络和服务数据条款以验证结果为准。执行与验收见 [分期开发计划](development-plan.md)。

## 架构与决策

| 决策 | 推荐 | 取舍 |
| --- | --- | --- |
| D1 安卓 | Kotlin、Jetpack Compose Canvas 绘制原创脸，协程串行归约状态，AudioRecord / AudioTrack 流式 PCM。建议 minSdk 26、首验 Android 16，构建时锁定稳定 AGP、Gradle Wrapper、JDK 和 targetSdk | Compose 覆盖横屏、表情和触摸。最低 API 仅为工程边界，兼容承诺限现有 OPPO |

| D3 云语音 | 首测阿里云百炼 Fun-ASR-Realtime、Qwen Flash 文本流式、CosyVoice Flash 系统音色和双向 WebSocket。按工作空间确定地域、固定模型快照和音色 | 分层能分别验证童声、延迟和合规，也允许应用控制句级播放与玩法；代价是串联延迟。ASR 次选 Qwen-Audio-ASR-Streaming，沿用同一验证集和数据门槛 |
| D4 后端 | Python 3.12、FastAPI / Uvicorn 单进程，HTTPS/WSS，端到端异步流，单机单应用。开发使用模拟适配器 | 一台手机、一个活跃会话。音频经后端便于统一截止时间、取消与鉴权，代价是两跳和服务器带宽 |
| D5 上下文与玩法 | 安卓控制现场音频和会话生命期。后端内存持有临时对话及确定性游戏状态。LLM 负责短句表达及受约束的候选意图 | 规则保证题目、进度和退出；停机或断连清空，连通后建立新会话 |
| D6 分发 | 使用固定签名的版本化 APK，由用户在个人 Mac 安装并验收。V0 和模拟可独立构建 | 签名材料保存在用户授权的仓库外位置。V1 运行只需手机与获准后端及服务 |

## 前台音频与交互

横屏亮屏，始终可触及停止。普通触摸立即叠加短表情，结束时由当前状态重新渲染。麦克风权限被拒、音频焦点丢失、路由变化导致录音失效时，由同一清理路径释放音频；可重新显式开始，按权限状态显示引导。失去顶层前台、锁屏或系统中断时清空并释放；恢复后仅重新待机。播放前取得焦点，播放结束或停止时归还。音频所有权由一个协调器串行切换，录音和播放互斥。

- 待机使用一个 16 kHz、单声道 PCM16 AudioRecord，同时向 KWS 和端上内存环形缓冲送帧。约 3 秒缓冲是实验起点；每帧携带单调采样位置。KWS 命中后按关键词结束时间映射到采样位置，回读尾部、保留保护区并接续同一个录音流。快照与订阅在同一顺序队列交接，以绝对帧位置去重并检测缺口。
- 命中后先保留音频，短观察窗内若唤醒词后有语音，连续采集指令并流式发送已触发窗口；指令分支不插播唤醒回应。后端只清理转写开头已确认的唤醒词，指令其余部分保留。时间边界不准时扩大有限保护区并验证漏首字、重复词和紧贴发音。缓冲缺口或不明确结果走简短确认。
- 若观察窗结束且没有后续语音，停止录音、清除缓冲、播放内置简短回应。等实际播放结束和音频资源释放后自动开始新轮聆听。短观察窗、保护区和播放后防回授间隔均通过 OPPO 真机时序测量校准，尤其验证孩子边想边开口和紧接回应说话。
- 开始说话使旧会话失效，清完旧输出后开启新录音。录音启动成功且收到帧后点亮聆听表情。端上 VAD 判定语音开始与结束，允许思考停顿。手动结束走同一封口路径，仅处理有效语音。无有效语音时不提交对话轮；连续无回应只温和追问一次，再超时则退出。正常答复播放完成后自动聆听。告别播放完即清空，停止键随时可跳过。
- 普通轮只上传检测到语音的有界窗口，含短预卷和必要尾部；游戏依赖网络。断网、超时、识别失败结束旧交流，播放本地固定提示并提供显式重试。待机网络连接可预建立，仅传心跳；断开不续传。网络恢复后可开始新交流，本地表情和触摸一直可用。

## 状态与事件

状态包含 `Inactive`、`WakeIdle`、`WakeFollowup`、`StartingCapture`、`Listening`、`Waiting`、`Speaking`、`CleaningUp`。网络与权限为入口条件，聊天／游戏模式独立于音频状态。音频所有权以资源确认事件为准。

| 事件 | 转移及条件 |
| --- | --- |
| 前台可用 / 退后台、锁屏 | 进入本地待机 / 立即失效并释放到 Inactive |
| 唤醒命中 / 观察窗到期 | WakeIdle → WakeFollowup → Listening 或本地回应 |
| 开始说话 / capture_ready | 先清理旧资源 → StartingCapture → Listening |
| VAD 或手动结束 | Listening → 停收并封口 → Waiting，空语音进入无回应路径 |
| 收到可播放音频 / 播完 | Waiting → Speaking，只有当前轮可播。播完进入下一轮或待机 |
| 停止 / 超时 / 断网 | 即刻撤销有效身份并清输出，CleaningUp 完成后进入前台待机或 Inactive |

每次新会话分配随机 `sessionId`；`turnId` 在会话内递增；本地 `generation` 在取消、替换、清理开始时增加。全部异步生产者在创建时固定身份，回调经同一串行事件队列，只对当前身份和允许状态有效（包括 UI、错误、VAD、计时器和播放完成）。资源释放完成以协调器操作号关联，不能重新进入已取消轮次。

停止先原子撤销并静音，取消读写任务、丢弃待播 PCM、清除表现队列、停止并释放录音/播放，再异步尽力发送 cancel。等待旧音频停妥再授予新录音所有权。清理超时时保持资源不可用，走明确失败和重建，避免并行占用。后端收到 cancel/断连/过期，取消供应商任务或关闭对应流，立即移除业务引用，丢弃任何迟到回调。重复 start/stop、重复封口及取消保持幂等，排队操作仅由最新合法意图生效。

## 流协议与上下文

WSS 单连接，版本化 JSON 控制帧与带头部的二进制音频帧混合。控制消息含 `v`、`sessionId`、`turnId`；音频另含序号、方向、回复分段号及采样位置。校验身份、顺序、帧长度和终止状态，限制帧/队列，队列溢出以明确错误终止整轮。

- 手机 → 后端：`session.start`、`turn.start`、PCM、`turn.end`、`turn.cancel`、`session.end`、`playback.segment_completed`。后端 → 手机：`turn.ready`、可选 `asr.status`、`reply.text_segment`、`reply.audio`、`reply.effect`、`reply.end`、`turn.error`。
- ASR 边说边上传，收到封口再等最终转写；部分结果不推动玩法。LLM token 先组成短完整语义段，每段通过安全检查后排入 TTS，正文、音频、表情分别发送。同一分段音频按顺序播；效果只允许预定义表情/揭晓动作，绑定当前轮和规定播放点，晚到或无效则丢弃。图片仅随揭晓动作出现。
- 播放完成以 AudioTrack 播放头达到分段末尾并通过当前身份校验为依据。ACK 幂等且只接受连续完成段。切换到下一轮前先按连接顺序发出 ACK。后端对话只记录已确认播放的段，部分播完时保留已完成前缀与「上一回答未说完」状态；全部未播不得当成已说。停止/重开/断连直接删除整个会话。分段对应的游戏关键转移随播完确认提交，例如揭晓和题数；图片在答案段播完后展示，正常播完再自动进入下一题。
- 临时预算起点：单客户端最多一轮，上传 20 秒、起始无回应约 6 秒，自动尾静音从 0.8 秒试起，封口后 8 秒仍无可播回复则超时。传输积压上限以约 1 秒音频试起，供应商未就绪且溢出时明确失败。会话空闲兜底 TTL 60 秒，最近 4 轮已确认内容并设字数上限。无隐式重试或旧轮重放。

## 猜动物与内容控制

固定审核题库每条有动物 ID、同义词、递进线索、图片及授权来源。服务端无放回抽取，保存已出集合和完成数。建议首批至少 12 题。替补耗尽时告知并结束本局，保留跳过不计完成的规则。三题完成后仅明确答应才开新局。

高优先级依次处理安全、退出/切换、提示/不知道/跳过、答案、偏题。规范化同义词，空白、冲突、模糊或转写不确定先确认；猜错给新线索，连续猜错或线索耗尽就询问是否揭晓。孩子拒绝后仍可猜或跳过。猜对或揭晓才增加完成数。允许短暂接话后回到题目，明确想聊天即清局。游戏以审核过的固定话术和题库为主，自然意图分类只接受限定枚举与题库 ID，低置信回退到确认。

聊天限制 1–3 个短句，先对输入做安全分流，每个语义段过输出规则再允许合成。身体不适、受伤、害怕及危险要求用固定短句引导找家长，疑似风险时优先用审核话术。模型无工具访问或设备控制权限，表情仅使用白名单。云服务失败时用本地提示并退出旧会话。

## 隐私与运行

麦克风待机环形缓冲只在手机内存，未命中滚动覆盖；上传只在唤醒/显式开始后的有效会话及续轮触发。App 和服务仅在内存处理当前会话，结束、锁屏、断线、崩溃重启或 TTL 到期清除引用；禁用正文追踪、请求体日志、崩溃附件和 core dump，检查代理、SDK、系统转储与交换分区的落盘风险，正式语音服务须验证进程内存不会写入未受控交换空间。日志仅聚合耗时、状态、计数、错误码、版本和计费用量；不用固定儿童标识。测试证据也仅提交指标和脱敏事件轨迹。

后端机密由用户授权注入，保存在应用目录外；APK 中没有服务密钥。一次性管理员配对码换取单设备可撤销凭据，客户端以 Android Keystore 保护本地凭据，再换短效连接令牌；令牌不放 URL 或日志。私有访问优先，只在用户授权后配置 TLS 接入；应用限制连接数、请求大小、速率和用量。签名和配对由成人在安装时完成。

百炼中国站 FAQ 说明调用数据可能存储；国际站零留存能力按客户资格和模型范围提供，不能据此推断本方案三段都适用。童声云测前逐项取得所用账号、地域及 ASR/LLM/TTS 的音频/文字数据处理范围、留存时长及例外、删除能力、训练使用、访问与转移条件，由用户确认适用性和监护人授权。生产配置和试验配置各自核对，未过关时用模拟和合规范围内的成人验证推进；候选不合格则替换对应适配器并再验。 [中国站 FAQ](https://help.aliyun.com/zh/model-studio/faq-about-alibaba-cloud-model-studio) · [国际站数据留存说明](https://www.alibabacloud.com/help/en/model-studio/data-retention-policy)
