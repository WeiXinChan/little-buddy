# 猜动物 D 手机独立运行设计

以 main `e3a97b1a148da4e6002c1a7aad9af3a9a88f77e5` 的 [需求](../requirements.md)、[里程碑合同](animal-guessing-milestone.md)和[私有语音验证](animal-private-validation.md)为基线。TITA-21 本次交付设计。实施门槛为 TITA-17 独立设计复核、TITA-33 本方案复核、用户授权、PR #6 语音基线或等效变更获准，以及 C 的可体验 APK 与前序验收证据。PR #16 与 TITA-31 的结果由原流程交付。

## 推荐接入

```text
OPPO → wss://<获准子域>/v1/animal（443，公有 CA）
     → Nginx 精确路由 → wss://127.0.0.1:<独立端口>/v1/animal
     → 现有游戏后端 → 百炼北京 Fun-ASR / CosyVoice
```

复用单服务器、规则题库、供应商模型和协议。只新增一个专用虚拟主机和非 root systemd 实例，独立端口、服务用户、凭证映射及日志范围。代理向回环后端继续走 TLS，启用上游验证与 SNI，使用专用服务端证书和代理侧信任文件，核对 SAN 与配置的上游名。原 8443、8444、9444 及旧证书和凭证由原私有服务保管。云模型配置由授权管理员在服务器映射既有凭证，APK 仅使用独立设备令牌。

入口仅允许指定主机与精确游戏路径的 WSS Upgrade，HTTP/1.1 透传 Upgrade、Connection 和单个 Authorization，拒绝重复头、查询串、其他路径、浏览器 Origin 和默认虚拟主机请求。健康检查仅在回环执行。禁止明文游戏请求。用 DNS-01 签发时无需新增 80 监听。443 若已由可复用代理占用，先审阅独立虚拟主机变更和回退方案。若需要改动原私有服务或争抢监听，暂停。

截至 2026-11-23，工信部要求在境内从事互联网信息服务的 APP 履行备案义务。腾讯云中国大陆域名接入规则要求核对备案及接入状态。上线前由运营方确认实例地域、接入商、域名控制权及该家庭试验的备案和接入条件。域名归属与备案状态目前未知，单设备与 Bearer 鉴权均不能作为豁免依据。 [工信部 APP 备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html) · [腾讯云接入备案](https://cloud.tencent.com/document/faq/243/43878)

无域名时，Let’s Encrypt 可签公有 IP SAN 证书，寿命 160 小时。Certbot 的 IP webroot 路径需 5.4+，要验证外部 ACME 可达、自动续签、部署后 reload、实际 OPPO 信任链与 IP SAN。腾讯云区分直接 IP 测试与经 IP 提供互联网信息服务，后者仍有备案要求，且其系统暂不支持直接使用 IP 备案。只有接入方与运营方确认本试验适用条件，且续签和手机校验均通过，才考虑用 IP 做短期试验。否则保留现有私有联调，曾有合规受控网络时可另审其可达与信任条件。Android 家庭包使用系统 CA、默认服务端身份校验和禁明文策略。移除手机测试 CA 后验证正常连接及错误主机名、未知 CA、过期证书均失败。 [Let’s Encrypt IP 证书](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability) · [Certbot 续签](https://letsencrypt.org/2026/03/11/shorter-certs-certbot) · [腾讯云测试与 IP 备案规则](https://cloud.tencent.com/document/faq/243/19630) · [腾讯云备案场景](https://cloud.tencent.com/document/product/243/18910) · [Android 信任配置](https://developer.android.com/privacy-and-security/security-config)

## 设备、会话与费用控制

- 现有 `backend/animal/cloud.py` 在升级时校验单个 Bearer、单活动会话，限制帧 6406 字节、队列 4、握手 4 秒、Ping/Pong 5+5 秒，应用首包 5 秒、局内事件 30 秒、局内循环 900 秒。上线需在入口再限握手和连接，建议每源 6 次/分钟加突发 3、全局 30 次/分钟，后端保留单设备单会话。代理读写空闲建议 20 秒，OPPO 实测心跳穿透与移动网络抖动后调整。防止已升级连接绕过预算，配额须在后端发起 ASR/TTS 前扣减。
- 服务端生成至少 256 位随机值，例如 64 位十六进制字符，单设备独占，建议首期 7 日到期。由家长经已验证的私密渠道取得并在成人设置一次输入。端上用 Android Keystore 密钥保护加密存储，排除备份和诊断导出。服务器经受限 systemd 凭证文件注入，停服时清除。轮换时暂停新握手并关闭旧连接，替换凭证重启专用实例，再由家长录入新值。到期或撤销应关闭已有连接并切断旧令牌，即使无人操作到期也执行。验收以旧令牌握手被拒、旧连接退出、新令牌能开新局为证据。
- 点击开始仅启动一个连接。沿用会话、轮次、listen ID 与播放回执守卫。ASR ready 前零 PCM，重复开轮、无声提交及旧回执不得造成重复上游调用。退出、切后台、锁屏或网络中断时先使本地会话代次失效，释放录音、播放与焦点，再取消 WS。服务器以关闭事件或心跳超时取消并等待上游任务退出、清除局和释放槽位。清理只生效一次，迟到事件不更新 UI。恢复网络时提示重新点开始，创建空局。局末正常说「再玩一局」沿用当前已认证连接的既有状态机。
- 百炼北京公开单价按 ASR 0.00033 元/秒、TTS 1 元/万计费字符估算，汉字按两个字符。假设一局 60 秒 ASR、600 计费字符，约 0.080 元。一期建议单设备日配额 600 秒和 6000 计费字符，按公开单价约 0.80 元/日，7 日约 5.59 元。ASR 起流前按最大录音长度保守预占，TTS 请求前按计费字符预占，失败或取消保留已提交用量，进程重启后配额继续有效；控制台计量差异、其他实例、网络和基础设施费用另计。管理员日核对账单，超额或异常立即停专用入口。游戏用规则判断，费用估算不含后续聊天。 [百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)
- 诊断仅保留聚合握手状态、匿名关联号、错误类别、时延、ASR 秒数、TTS 计费字符和完成题数。应用及代理试验日志滚动 7 日、合计上限建议 50 MiB。关闭原始访问日志或在写入前剔除地址及请求头等字段，禁止保存令牌、录音、转写和聊天正文。百炼侧数据处理、留存及家长同意走总设计的数据放行关卡，未放行仅用合成音或成人输入。

## 授权后的部署与停服

1. 核对云实例地域、接入条件、域名与预算。通过已有可信管理入口检查 80/443 监听、Python 3.11+、依赖固定版本、systemd、代理/ACME 版本、可用内存和磁盘。记录非敏感元数据。本轮对既有主机发起一次严格校验的只读 SSH 尝试，本地缺少可信 ED25519 主机记录，远程命令未执行，因此端口占用、版本、磁盘及资源余量均未验证。已知 4 核 4 GB、3 Mbps 为任务给定值。PCM16 16 kHz 上行 256 kbps、24 kHz 下行 384 kbps 为净荷估算，需实测共享带宽、内存峰值及音频开始延迟。重型任务按 [发布锁](build-and-release.md) 串行。
2. 签出获准 SHA，串行准备独立实例及依赖，先用回环、假供应商和试验令牌验证精确路由、证书、拒绝路径、限流、到期及断线清理。需新增的代理、依赖、防火墙/安全组、DNS、证书签发、续期任务、凭证映射和公网监听均待授权执行。持有备份后验证代理配置，获准才放行 443 并测试外部 WSS。记录证书到期、续签演练及重载结果，续签首次失败告警，证书失效停止服务。
3. 按 [签名发布流程](build-and-release.md) 登记 APK 与服务端兼容组合、协议/题库版本、Git SHA、包名、递增 versionCode 和签名指纹。独立试用线首包使用用户控制的发布签名，随后同包名同签名覆盖升级，验证旧包设置迁移及旧私有地址不会自动用于试用。测试 debug 包若签名不兼容，使用独立试用包名并行安装。受限渠道交付验签报告、APK、SHA256SUMS 和停服说明。旧代码需回退时重新签发递增版本，兼容上一已验证服务协议。
4. 签名包与服务先通过负向验证，再由家长验收 OPPO。停服时首先阻断新握手，撤销试验令牌并结束活动连接，确认上游归零后停止独立实例。移除专用路由、DNS 与专用防火墙放行，若共享 443 则保留其他路由。停专用续签任务，泄露时撤销专用证书，清理试验凭证和到期日志。原私有联调按原文档恢复。记录拒绝旧令牌、旧端点失效及原私有服务健康结果。

## 真机验收与完整 V1

| 用例 | 通过条件 |
| --- | --- |
| 独立开始、三题、再玩 | 拔 USB、移除 ADB reverse 与测试 CA、结束 SSH、关闭 Mac。OPPO 在家庭 Wi-Fi 和移动网络分别确认可连接，完成三题一次，语音再玩从新题局开始 |
| 断网、重开 | 在听音与播放各断网一次。客户端释放麦克风和播放器，服务器在心跳窗口后确认上游清理与槽位释放。恢复后点开始，新会话无旧图、旧音与旧题进度 |
| 退出、后台及锁屏 | 试听和播放时分别验证退出、切后台与锁屏；无残留录音、播放或供应商任务，重复点击和迟到回执不串局、不重复计费请求 |
| 安装与失败 | 首装和同签名升级各验证一次。无效/过期令牌、错误 TLS、满额和代理不可达均可辨识并安全退出 |
| 记录 | 包与服务 SHA、OPPO/ColorOS/network、各用例次数和结果、讲话结束至开播耗时及百炼用量。3 秒为需求目标，成人结果由用户验收并独立标注，童声结果待数据关卡及单独实测 |

本次仅规划点击猜动物独立体验。完整 V1 后续先接入前台本地「瓦力瓦力」唤醒与音频互斥，再接简短聊天、聊天与游戏双向切换和空状态。按 [验收基线](acceptance.md) 在独立手机环境联合跑 A1/A4。鉴权握手独立签发首意图许可。单独唤醒等待本地播放释放，紧接首意图保留同流且 ready 前零 PCM；重复握手、语音和无声提交按夹具验证只消费一次。覆盖游戏切空聊天、聊天切空局、旧模式事件隔离、退出后前台唤醒待机、重复启动、锁屏、停止前后迟到回执和旧许可拒绝。

## 评审后待决定

1. 接入方式。推荐复用具备控制权且符合接入规则的域名子域。缺少域名时，先核实短期 IP 试验条件；条件不成立就保留私有联调。
2. 试用授权。确认是否授权按上述 TLS 路径开放 443、单设备 7 日试用、私密交付令牌及建议用量上限。证书、DNS、安全组、部署、发包及付费动作按实际授权执行。本期设计无新增采购或用量。
