## 来源与使用

scripts/assets/build-defaults.py为本次本地原创矢量绘制和离线渲染，不是提示词交付。所有图形在用户授权任务内绘制，供本项目保存、修改及后续集成；没有外部素材再分发许可依赖。逐张来源、项目用途许可说明、尺寸与SVG/PNG双格式SHA-256见manifest.json。不宣称AI贡献在任何司法辖区有独占著作权，不额外替全仓指定开源许可证。

## 复现

实际依赖Python3、CairoSVG 2.9.1、Pillow 13.0.0，安装在仓库外隔离目录。无在线生成调用或付费开通。

    python3 scripts/assets/build-defaults.py
    python3 docs/evidence/tita85/write-review.py
    python3 scripts/assets/check-defaults.py

首脚本重绘源图/PNG/拼页，次脚本保存本次作者观察。画面更改必须实际重新视觉检查，不能沿用旧记录。完整检查记录在docs/evidence/tita85/visual-review.md；五张实际拼页在同目录。

## 验收边界

这是60张真实候选覆盖集，等待协调方安排非作者逐张质量审查，不是A15最终通过。目标手机屏幕、比例适配、语音展示门控、临时图清理、动态生成、服务故障拒绝路径均未接入或测试；A13–A16/A23整体OPEN。不能将静态图哈希当成生成一致性证明。

推荐后续集成采用contain保持比例，空白区域沿用柔和背景。准备完成与展示资格分开：最终消费时验证会话/轮次/话题/代际与已播揭晓门槛；取消/换人/过期使旧资格失效。缺图或语义不符保留眼睛，不得凑图。只可采用经独立审定素材。

本轮没有确认具体图片生成模型、数据保留/训练条款与计费授权，故未调用既有百炼等图片服务。语音服务授权不能推导为图片服务授权。本地原创已覆盖默认数量，特殊想象的在线生成仍待后续核验，不上传儿童会话或身份信息。
